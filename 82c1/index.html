Limits of Sequences

First, I would like to note that all the discussions will be based on R\mathbb{R}R, and the discussions will not involve metric spaces. Before we continue, we need to state two axioms.

Axiom 1 (Archimedes' axiom)

For every $a, b > 0$, there exists $N \in \mathbb{N}$, such that $b < Na$.

Axiom 2 (Cantor's axiom)

${a_n}$ and ${b_n}$ are two given sequences satisfying ${a_n} < {b_n}$ for every $n$, with associated intervals $[a_n,b_n]$ nested and their lengths tending to zero. Then there exists a unique $c$ such that $\bigcap\limits_{n=1}^{\infty} [a_n, b_n]=\{c\}$.

These axioms will be used later.

1.1 Definition

For every $\varepsilon > 0$, there exists $N \in \mathbb{N}$ such that for all $n \ge N$, $|a_n - \alpha| < \varepsilon$. We write $a_n \to \alpha$ as $n \to \infty$, or

$\lim\limits_{n \to \infty}a_n = \alpha$

We call $\alpha$ limit value and we say the limit of sequence $\{a_n\}$ is $\alpha$ or $\{a_n\}$ converges to $\alpha$

1.2 Theorem

If $\{a_n\}$ is convergent, the limit is unique.

Proof. Suppose that there are two different limit values, $\alpha$ and $\beta$. Since $\alpha \ne \beta$, we let $\varepsilon=\frac{|\alpha - \beta|}{2}$. By 1.1 Definition, there exists an $N \in \mathbb{N}$, such that for all $n \ge N$, $|a_n - \alpha| < \varepsilon$ and $|a_n - \beta| < \varepsilon$ (taking the larger $N$ if necessary). Then we have $|\alpha - \beta| = |(a_n - \alpha) - (a_n - \beta)| \le |a_n - \alpha| + |a_n - \beta| < 2\varepsilon = |\alpha - \beta|$. This is a contradiction.

$\square$

1.3 Theorem (Squeeze Theorem)

Let $\{a_n\}$, $\{b_n\}$, $\{c_n\}$ be sequences of real numbers. Suppose that $\{a_n\}$ and $\{b_n\}$ converge to $L$, and also suppose that for every $n$, we have $a_n < c_n < b_n$. Then $\lim\limits_{n \to \infty} c_n = L$.

Proof. Since $\{a_n\}$ and $\{b_n\}$ converge to $L$, it follows that for every given $\varepsilon > 0$, there exists an $N \in \mathbb{N}$ such that for all $n \ge N$, $|a_n - L| < \varepsilon$ and $|b_n - L| < \varepsilon$. Moreover, since for every $n$, $a_n < c_n < b_n$, we obtain $a_n - L < c_n - L < b_n - L \Rightarrow -\varepsilon < c_n - L < \varepsilon \Rightarrow |c_n - L| < \varepsilon$. Hence $\lim\limits_{n \to \infty} c_n = L$.

$\square$

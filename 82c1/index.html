Limits and Continuity

Created2026-07-25|Updated2026-07-26|讲义
|Post Views:

Introduction

In this post, I will discuss limits and continuity. There are 3 purposes for writing this post: 1. To practise my academic writing. 2. To write for fun. 3. To expound some points that I was stuck on for a while at first when I was learning as an undergraduate in my first semester. It may help someone, or not, because the main purposes actually are 1&2.

I hope you can enjoy the read.

Limits of Sequences

First, I would like to note that all the discussions will be based on ℝ, and the discussions will not involve metric spaces. Before we continue, we need to state two axioms.

Axiom 1 (Archimedes’ axiom)
For every a, b > 0, there exists N ∈ ℕ, such that b < Na.

Axiom 2 (Cantor’s axiom)
an and bn are two given sequences satisfying an < bn for every n, with associated intervals [an, bn] nested and their lengths tending to zero. Then there exists a unique c such that $\bigcap\limits_{n=1}^{\infty} [a_n, b_n]=\{c\}$.

These axioms will be used later.

1.1Definition For every ε > 0, there exists N ∈ ℕ such that for all n ≥ N, |an − α| < ε. We write an → α as n → ∞, or $$ \lim\limits_{n \to \infty}a_n = \alpha $$

We call α limit value and we say the limit of sequence {an} is α or {an} converges to α

Remark. If for every M > 0, there exists an N ∈ ℕ such that for all n ≥ N, an ≥ M, then it means that the sequence {an} does not converge(it diverges). Furthermore, the sequence diverges to positive infinity(for an ≤ M, we say the sequence diverges to negative infinity). We write: limn → ∞an = +∞   an → +∞ (n → ∞)

or

limn → ∞an = −∞   an → −∞ (n → ∞)

1.2 Theorem If {an} is convergent, the limit is unique.

Proof. Suppose that there are two different limit values, α and β. Since α ≠ β, we let $\varepsilon = \frac{|\alpha - \beta|}{2}$. By 1.1 Definition, there exists an N ∈ ℕ, such that for all n ≥ N, |an − α| < ε and |an − β| < ε (taking the larger N if necessary). Then we have |α − β| = |(an − α) − (an − β)| ≤ |an − α|+|an − β| < 2ε = |α − β|. This is a contradiction.

□

1.3 Theorem (Squeeze Theorem) Let {an}, {bn}, {cn} be sequences of real numbers. Suppose that {an} and {bn} converge to L, and also suppose that for every n, we have an < cn < bn. Then $\lim\limits_{n \to \infty} c_n = L$.

Proof. Since {an} and {bn} converge to L, it follows that for every given ε > 0, there exists an N ∈ ℕ such that for all n ≥ N, |an − L| < ε and |bn − L| < ε. Moreover, since for every n, an < cn < bn, we obtain an − L < cn − L < bn − L ⇒ −ε < cn − L < ε ⇒ |cn − L| < ε. Hence $\lim\limits_{n \to \infty} c_n = L$.

□
